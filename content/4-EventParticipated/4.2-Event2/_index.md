#### Agentic AI for System Operations

Challenges in modern systems:

- Increasing system complexity due to Microservices architecture.
- Rapid growth of logs, monitoring, and observability data.
- Long incident investigation and troubleshooting processes.
- Rising infrastructure and operational costs.

Agentic Platform solutions:

- Automated incident investigation.
- Cloud cost optimization (FinOps).
- AI-assisted security testing.
- Faster incident resolution and improved operational efficiency.

#### Voice AI and AI Agents

Voice AI Architecture:

- Speech-to-Speech Architecture.
- Speech-to-Text → LLM → Text-to-Speech.
- Enterprise Voice Agent applications.

Live demonstrations:

- Building a Voice Assistant using Amazon Bedrock.
- Using Knowledge Bases to provide domain-specific information.
- Integrating AI Agents to answer product-related questions.

Challenges:

- Vietnamese is considered a low-resource language for AI training.
- More datasets and optimized language models are needed for the Vietnamese market.

#### AWS DevOps Agent

Common operational challenges:

- Logs and traces are distributed across multiple systems.
- Root cause investigation is time-consuming.
- Difficulties in collecting complete system context.

AWS DevOps Agent provides:

- Context Learning.
- Memory and Skill Learning.
- Integration with CloudWatch, Slack, and ServiceNow.
- Root Cause Analysis support.
- AI-generated recommendations for issue resolution and long-term improvements.

Typical workflow:

1. Incident detection.
2. Incident classification and investigation.
3. Solution recommendation.
4. Continuous system improvement.

#### AI in Human Resource Management

Common HR challenges:

- Time-consuming CV screening.
- Difficulty evaluating candidate quality.
- Challenges in employee retention.
- Increased workload caused by poor hiring decisions.

AI-powered solutions:

- Automated resume analysis.
- AI-generated recruitment insights.
- Workforce analytics and recommendations.
- Support for more effective HR strategies.
