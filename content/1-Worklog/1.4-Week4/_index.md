### Week 4 Objectives:

* Continue studying and practicing AWS Labs.
* Learn how to deploy web applications on AWS using Amazon EC2 and Amazon RDS.
* Study database backup, recovery, and management on Amazon RDS.
* Practice configuring Application Load Balancer and Auto Scaling Group to build scalable and highly available systems.
