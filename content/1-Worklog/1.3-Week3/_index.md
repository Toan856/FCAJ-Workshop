### Week 3 Objectives

* Continue studying and practicing AWS Labs.
* Learn AWS Identity and Access Management (IAM).
* Study AWS networking through Amazon Virtual Private Cloud (VPC).
* Practice deploying Amazon EC2 and configuring network connectivity.
* Learn how Site-to-Site VPN connects on-premises infrastructure with AWS Cloud.

### Week 3 Achievements

* Gained a solid understanding of AWS IAM for identity and access management.
* Successfully created IAM Users, IAM Groups, and IAM Roles.
* Learned Switch Role, Assume Role, and AWS Security Token Service (STS).
* Understood the Amazon VPC architecture, including VPC, Subnets, Route Tables, Internet Gateway, Security Groups, and Network ACLs.
* Successfully deployed Amazon EC2 instances and monitored them using Amazon CloudWatch.
* Learned about NAT Gateway, Reachability Analyzer, and AWS Systems Manager.
* Studied the architecture and deployment process of Site-to-Site VPN between on-premises infrastructure and Amazon VPC.
* Strengthened knowledge of AWS infrastructure management, networking, and security.
