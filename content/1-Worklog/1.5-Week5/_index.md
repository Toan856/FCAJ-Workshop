### Week 5 Objectives:

* Learn about Amazon S3 object storage on AWS.
* Practice creating and managing Amazon S3 Buckets.
* Deploy a static website using Amazon S3.
* Study content delivery through Amazon CloudFront.
* Learn data management and security features including Bucket Policy, Versioning, and Object Ownership.

### Week 5 Achievements:

* Understood the architecture and operation of Amazon S3 and the Object Storage model.
* Successfully created and managed Amazon S3 Buckets following AWS security best practices.
* Successfully deployed a static website using Amazon S3.
* Learned how to upload, manage, and update objects in Amazon S3.
